# Security

Please do not include credentials, profiles, exports, browsing histories, or
private screenshots in a public issue. For a potential vulnerability, use GitHub's
private vulnerability reporting when available, or first request a private contact
without publishing exploit data that exposes anyone's credentials.

This early release is a local migration utility. It does not provide a new
password vault, promise memory zeroization, or guarantee that every browser version
or third-party session can be migrated. Keep original profiles and verified backups.
