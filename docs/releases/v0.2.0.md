## arc_to_zen 0.2.0

A macOS desktop app and CLI for moving Arc spaces, Essentials, tabs, and folders to Zen with full local backups and verification before commit.

### What's new

- Renamed the application, Python package, and commands to `arc_to_zen`.
- Redesigned the desktop interface with a navy sidebar, light slate surfaces, blue accents, guided navigation, and migration count summaries.
- Improved preview invalidation and disabled browser selection controls during active operations.
- Reorganized the README with installation instructions, direct downloads, CLI examples, privacy details, and recovery guidance.
- Preserved existing migration ownership records and legacy backup discovery. Previous CLI command names remain available as aliases.

### Downloads

Choose `arm64` for Apple Silicon (M1 and later) or `x64` for Intel. Both require macOS 14 or later.

- **ZIP:** Extract and move `arc_to_zen.app` to Applications.
- **DMG:** Open the disk image and drag the app to Applications.
- **SHA-256:** Each architecture includes checksums for its ZIP and DMG. Run `shasum -a 256 -c arc_to_zen-0.2.0-macos-ARCH.sha256` from the download folder after downloading both files for that architecture.

### Validation and compatibility

The release workflow runs the fixture-based regression suite, lint, formatting, and source privacy checks on both macOS architectures, then builds and verifies ad-hoc code signatures. Linux CI also validates the core test suite.

Builds are **ad-hoc signed, not Apple-notarized**. Use the normal macOS approval flow for trusted software. Browser formats vary; automated checks do not establish compatibility with every real browser profile. Read the [compatibility guide](https://github.com/MohamedRF/arc_to_zen/blob/v0.2.0/docs/compatibility.md) before migrating important data.

Arc is read-only. A separate Zen profile is the default. Quit both browsers before migration. Password transfer remains a separate opt-in CSV step using Zen's native importer; cookies require optional Keychain approval.
